Key state

A WebSocket client of driver/plugin for administering every key's color, emoji ID, and blink, and confirming each change against the daemon's own rebroadcast; requires macropadd --emulate or a real board. "Emoji char" sends an actual typed emoji as a custom glyph, rendered in this page with no server round trip — a plain letter is rejected, not rendered blank. To simulate a press instead, see virtualpad.html. See "Plugin API" in driver/README.md.
