# 0081 — A carrier PCB for the Pico and the six ScreenKeys

## Problem

The wiring inside the case takes too much room. Each key's cable ends in 9 Dupont leads on a
perfboard, the Pico sits in a female socket over male pins, and the shared lines run on parallel
male headers. Keith asked for a PCB he can upload to JLCPCB. It should take the Pico as a plug-in
and take the 6 keys as inputs.

## Goals

- A 2-layer board that JLCPCB can make from one Gerber/drill zip.
- The Pico Plus 2 plugs into two 1×20 female headers.
- Each key plugs into a 1.25 mm 9-pin socket, the same family as the module's own connector, wired
  pin for pin to the module's H2.
- The nets match `firmware/pins.py`: per-key DIN, CS and KEY, shared CLK, DC, RST and BL, plus 3V3 and GND.
- A 10 µF bulk cap on 3V3, and a header for the I2S mic on GP19–21.
- The board fits inside `panel_body.stl` between the corner blocks.

## Non-goals

- Mounting standoffs in the body. That's a follow-up once the board is in hand.
- Assembly by JLCPCB. Every part is through-hole and hand-solderable.
- Firmware changes. The pins don't move.

## Approaches considered

### Approach A — KiCad board generated by a script, autorouted by Freerouting

- Good, because the placement and nets are code that reads `pins.py`, so a pin change regenerates the board.
- Good, because Freerouting routes all 60 connections, and KiCad's DRC checks the result.
- Bad, because an autorouted layout is less tidy than a hand-routed one.

### Approach B — Hand layout in the KiCad GUI

- Good, because it gives the tidiest routing.
- Bad, because it's not possible from this environment and not reproducible from the repo.

### Approach C — Gerbers written directly from a script

- Good, because it needs no tools.
- Bad, because there's no DRC, and a router would have to be written from scratch.

## Decision

Approach A. `hardware/pcb/build_carrier.py` places the footprints from KiCad's stock libraries and
assigns the nets from `pins.py`. Freerouting routes the board, and the script then imports the routes
and pours GND on both layers. The cost is an autorouted layout, plus KiCad 7, Java and Freerouting
to rebuild it.

## Definition of done

- [ ] `carrier_jlcpcb.zip` uploads to JLCPCB with no errors, and the preview matches `carrier_top.png`.
- [ ] DRC: 0 unconnected pads and no clearance errors (`hardware/pcb/drc.rpt`).
- [ ] Every Pico pin goes to the net in `firmware/pins.py`. Checked with a continuity tester on a bare board.
- [ ] With the Pico and one key plugged in, the key shows a glyph and its press reaches the host.
- [ ] All six keys work through the board.
